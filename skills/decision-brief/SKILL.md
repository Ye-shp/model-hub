---
name: decision-brief
description: Compare products, technical approaches or business options against explicit criteria and documented evidence.
---
Extract the decision, constraints and measurable criteria from the task and project memory. Search imported evidence; compare each option using the same criteria. Flag unavailable or stale price/performance information rather than filling cells with guesses.

Ask a specialist to challenge the leading option and identify the circumstances in which another option wins. If frontier advice is enabled, send a focused question and only the necessary excerpts.

Deliver a comparison table, recommendation, assumptions and a small validation experiment. Save an actual decision only when the user or task has selected it; label your recommendation as a recommendation.
