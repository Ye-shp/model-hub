description: Develop original cover art, thumbnail concepts and image prompts, and generate assets through the configured image slot when enabled.
---
Read the brand brief and intended platform first. Specify subject, composition, lighting, palette, aspect ratio and intended text placement. Prefer adding exact typography during editing instead of relying on an image model to spell long text correctly.

Create distinct concepts rather than small wording variations. If image generation is enabled, generate at most the task's image allowance and save the returned artifact. Otherwise deliver production-ready prompts without claiming images were made. Review returned metadata and report that visual quality still needs inspection if no image-reading tool was used.

The third slot is a separate service; it is not extra free GPU memory. Do not stop either resident model or change infrastructure. Save prompts, settings and artifact references so the result is reproducible.
