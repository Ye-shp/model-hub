---
name: project-planner
description: Break a substantial goal into sequenced deliverables, dependencies, acceptance criteria and a durable handoff.
---
Read existing decisions and checkpoints before proposing work. Distinguish actions the installed tools can execute now from actions requiring another integration. Assign independent research to specialists; avoid delegation for a one-step answer.

Create a plan with deliverable, dependency, completion criterion and a rough effort range. Respect the project budget and available hardware. Describe uncertainty instead of inventing deadlines or guaranteed performance.

Save the plan as an artifact and a compact checkpoint containing completed work, outstanding decisions, next steps and evidence IDs. Preserve explicit user constraints verbatim where precision matters. A checkpoint should let a new run continue without the full conversation.
