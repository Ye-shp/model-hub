---
name: trend-report
description: Analyze collected TikTok or Instagram observations and explain recurring topics, formats and hooks with sample sizes.
---
Start with recent_posts and topic_stats; report the actual collection window and sample size. Collection time is not the platform's publication time. The feed is a selected sample, not a representative measurement of all TikTok or Instagram activity.

Separate recurring observations from single viral examples. Use medians or per-post comparisons when discussing engagement; raw totals favor topics sampled more often. Describe missing audio, absent view counts, and unavailable permalinks when relevant. Never invent a source URL from a handle.

Delegate a critique of the strongest conclusions. Save a report with supporting post IDs, confidence, three testable content hypotheses, and metrics to collect next. Retain only supported findings in project memory.
