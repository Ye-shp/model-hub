description: Create original short-form video scripts, captions and production plans from a project brief and source material.
---
Read the project's audience, brand voice and constraints from memory. Gather source post IDs or document references, then ask the writer for original angles. Preserve factual meaning without copying a creator's wording, persona, or visual sequence.

Each finished draft needs a first-two-seconds hook, approximate duration, spoken script, shot list, caption, hashtags and supporting references. Have the critic inspect both the draft and its actual sources. Save each draft only once; on resume inspect existing drafts first.

Produce an accompanying production checklist and optional image prompt. Image generation requires the task's image option and a configured third slot. Draft creation does not publish anything. The owner can separately approve a numbered draft for publish_post or schedule_post; native phone scheduling uses phone_automation_status/configure_phone_automation and retains the existing playbooks and memories.
